# ♾️ The #100DaysOfDevOps Challenge

Welcome to my official documentation and lab repository. This project is a dedicated 100-day journey to transition from a Computer Science student to a **Production-Ready DevOps Engineer.**

---

## 🎯 The Purpose of this Repo

This repository serves as my "Proof of Work."

While many learn in silence, I am **Learning in Public.** Every day for the next 100 days, I will be documenting:

- Technical deep-dives into Linux and Cloud architecture.
- Hands-on automation scripts and Infrastructure as Code (IaC).
- Real-world deployment failures and how I debugged them.
- Deployment pipelines for modern full-stack applications.

## 🚀 My Goal: Day 100

By the end of this journey, I will have transformed from a student into a Cloud-Native professional capable of:

- **Architecting** scalable infrastructure on AWS.
- **Automating** entire delivery pipelines using CI/CD.
- **Orchestrating** containerized workloads with Kubernetes.
- **Operating** with a "Stability First" mindset to support 24/7 application uptime.
